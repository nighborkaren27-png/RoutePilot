最新版使用方法

适用于路线助手 1.3.0。首次使用按以下顺序操作，之后可在主界面随时重新查看。

1. 开启定位与必要权限

开启手机定位服务，允许路线助手使用精确位置。建议允许通知，以便通过通知栏暂停、继续或停止。

进入手机开发者选项 → 选择模拟位置信息应用 → 选择「路线助手」。本程序不需要 Root 或 USB 调试。

2. 加载地图

在「规划路线」中选择「自动选择（备用优先）」。没有天地图 Key 时，先尝试 OSM France / HOT 备用地图，再尝试标准 OpenStreetMap；连接无响应约 12 秒会切换下一源，每轮仅尝试有限次。

地图空白时可切换地图源、点击「重新加载」，或换 Wi-Fi／移动数据。使用天地图道路图或卫星图，需要在「天地图 Key 设置」中填写自己有权使用的地图服务 Key。

所有在线底图都需要网络，不能保证在所有网络中可访问。地图不可用时，仍可通过坐标或 GPX 设置路线。

3. 设置路线与 GPX

点击「我的位置」，在停止模拟时获取真实位置；也可以输入 WGS84 纬度、经度找到地点。放大并点击地图，依次添加路线点，用「撤销」修改末点。

至少添加 2 个点，最多 10000 个点。各点以直线相连，不会自动沿道路导航。勾选「闭环循环」时，末点会连接起点并循环。

已有 .gpx 文件时，可展开「导入 / 导出 GPX」导入，或将当前路线导出保存。GPX 是路线文件，不能补充底图。请勿直接使用高德／百度坐标，以免偏移。

4. 设置速度与目标距离

速度范围为 0.5–30 km/h，默认 8 km/h；目标距离为 0–100 km，默认 2 km。目标为 0 表示不限距离。

关闭循环时，到达路线末点或目标距离即停止，以先到者为准。循环且目标为 0 时持续运行，需要手动停止。

5. 开始、暂停与停止

点击「开始模拟」后可切换其他应用。暂停时保留当前位置并发送速度为 0 的位置；继续后从该处移动。通知栏也提供暂停／继续和停止入口。

结束时点击「停止」以释放模拟位置。系统重新获得真实位置可能需要等待；使用其他导航前，请先停止模拟。结束后也可将手机模拟位置应用切回「无」。

荣耀手机如发生后台停止，可在「应用启动管理」中允许路线助手后台活动；不同系统的名称可能不同。

6. 卫星位置兼容

该模式为实验功能，默认关闭，需要停止模拟后才能切换。打开后提高位置发送频率并附带历史定位字段，耗电可能增加。

这项设置不增强真实卫星信号，不隐藏系统的模拟位置标记，也不模拟步频或步幅。无法保证消除其他应用的 GPS 弱提示或通过其检查。

7. GPS 弱时使用定位自检

分别在「停止模拟」和「开始模拟」后各点击一次「开始定位自检」。每次持续 30 秒，需保持路线助手页面可见；离开页面会结束自检。

自检展示定位权限、GPS 开关、模拟应用选择，以及本应用收到的位置回调次数、精度字段、数据时效、模拟标记和系统卫星状态。未收到卫星回调不等于卫星数为 0。

自检仅反映路线助手收到的数据，不代表运动世界等其他应用已接收或认可。遇到问题可记录两次自检结果，便于排查。

8. 本版本的范围

当前交付的是手机端定位模拟与自检应用。尚未包含手机虚拟安卓、系统传感器注入、步频／步幅模拟或反检测功能。其他平台是否接受模拟数据、是否计入成绩，仍需实际验证，程序不作保证。
