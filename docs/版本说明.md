# 路线助手 1.4.0 更新说明

本版可覆盖安装之前交付的版本，签名一致。覆盖安装后需要首次完成一次新版阅读确认；之后启动直接进入地图。清除应用数据或卸载重装后需重新确认。

- 免责声明仅首次自动展示；必须在免责声明正文滑到最底部，才可勾选「理解免责声明和使用须知」并进入。主界面可随时查看说明。
- 全屏地图、中心准星、添加中心点、比例尺及中心坐标；支持更高缩放。超过原生级别仅放大已有图片；更丰富的道路与卫星底图需选择天地图并填写自己有权使用的 Key，底图数据细节由服务决定。
- 底部快捷入口打开开发者选项、本应用设置；标准入口不可用时尝试后备设置页面。未逐品牌验证，部分系统仍需手动查找。
- 「预定位」会在起点持续发送静止位置，不累计模拟时间与里程；点击「继续」后开始移动。此功能不增强真实 GPS 信号。
- 显示已发送位置组数；自检区分精度未知、缓存位置，并说明结束后保留结果的数据年龄会继续增长。

## 关于收到的自检截图

模拟运行时，本应用收到 GPS 和 network 标记为模拟的位置回调，说明本应用的系统回调通道能收到模拟数据。它不能证明运动世界采用了相同数据，更不能证明它会计入成绩。精度 1 / 2 m 是模拟位置附带字段，不是实测误差；未收到 GNSS 回调不等于实际卫星数为 0。自检结束后的三十多秒年龄，不足以单独说明后台发送停止。

可先预定位再继续，并观察本程序发送计数是否持续增加。仍出现第三方信号弱时，不能仅依据本应用自检断言问题已解决。本程序保留系统模拟标记，不模拟步数、步频或步幅。

## 验证范围

APK 编译及签名验证通过；首次阅读门槛、界面数据、自检文案和地图源检查通过；320 / 412 px 浏览器预览确认全屏地图与阅读流程。浏览器使用测试桥接，不代表安卓真机验证。

没有连接安卓真机，尚未验证荣耀 MagicOS 11 / Android 17 和运动世界 7.4.0 的实际运行或设置跳转，不保证消除其 GPS 弱提示。
