# 路线助手 1.3.0

本版本加入你确认的“免责声明与使用须知”以及最新版使用方法，并将功能名称统一改为“卫星位置兼容”。

## 更新安装

直接打开 `RoutePilot-1.3.0.apk` 覆盖安装。包名与旧版相同、签名相同，版本号提高到 1.3.0，保留本机路线和设置；如有重要路线，建议先导出 GPX 备份。

## 启动界面

- 全新打开应用时先进入启动说明页，包含“免责声明”“最新版使用方法”两个页签。
- 免责声明采用你最后编辑确认的原文，保留 B站用户“后藤一里的发带”署名、完全免费说明和开源组件条款。
- 勾选“我已阅读并理解免责声明与使用须知”后，可点击“同意并进入”。选择“不同意并退出”会退出；若此前的模拟服务仍在运行，也会停止模拟。
- 本次活动界面已确认后，屏幕旋转等界面重建会保留确认状态，避免重复确认。新建启动流程会重新展示。
- 主界面顶部有“使用方法与免责声明”，可随时重新查看；查看说明不会自动停止正在运行的模拟。返回主界面后仍可操作暂停和停止。
- 启动说明页的正文和样式内置于 APK，可离线阅读；首次确认进入主界面前不会加载在线地图。

## 内置使用方法

内容覆盖定位权限、模拟位置应用选择、备用地图和天地图设置、地图选点、坐标与 GPX、循环路线、速度和目标距离、后台运行、暂停停止，以及定位自检。

“卫星位置兼容”仅为原兼容功能的新名称，仍默认关闭并标注实验性质。未加入真实卫星增强、手机虚拟安卓、步频／步幅模拟或反检测功能。

## 验证

已检查启动页页签、确认按钮、主界面入口、返回流程及 320 / 412 像素宽度布局；检查了免责声明正文与确认稿的文本一致性。APK 编译与签名验证通过，签名与 1.2.0 一致。现有地图控制和前端数据契约检查通过。

界面交互使用浏览器测试桥接验证；未进行安卓真机安装、退出服务行为或运动世界有效性测试。
